# plsremind for Discord

The Discord bot of [plsremind](../../README.md). It sends your reminders as direct messages
and lets you deal with them there:

- A reminder arrives with three things to do: mark the item done, be reminded again later,
  or open it in the dashboard. Completing it elsewhere updates the message.
- `/remind when what` reminds you once at a time of your choosing.
- `/deadline due what` adds an item with a deadline. You are reminded as your reminder plan
  for its priority says.
- `/todos` shows what is open, with a page for each item: its steps, its next reminder,
  edit and delete.
- `/done item` completes an item.
- "Remind me" in the menu of any message (Apps) reminds you of that message and links back
  to it.

Answers are only visible to you. `public_ack` on `/remind` and `/deadline` posts the
confirmation in the channel instead; the note stays private either way.

Times can be typed the way you would say them, in English or German:

| You type | It means |
|---|---|
| `10m`, `2h`, `3d`, `1w`, `1h30m`, `in 2 hours` | that long from now |
| `18:00`, `9`, `9am`, `6pm`, `18 uhr` | the next time it is that late |
| `today`, `tomorrow`, `fri`, `friday`, `morgen`, `freitag` | that day |
| `24.12.`, `24.12.2026`, `2026-12-24` | that date |
| `tomorrow 9`, `fri 18:00`, `24.12. 10:00` | that day at that time |

A day without a time is an all-day deadline for `/deadline` and 09:00 for a reminder.

To use the bot, add it to your Discord account with the install link of the instance you
use and link your Discord account in the dashboard under Settings.

## Running it

See [docs/self-hosting.md](../../docs/self-hosting.md#the-discord-bot). The bot is one
process configured through environment variables; it talks to the hub through the API and
the gateway only.

## Working on it

It needs Python 3.15 and [uv](https://docs.astral.sh/uv/). The tests against a real hub
also need Go and Docker.

```sh
uv sync --all-groups
uv run nox                                   # format, lint, types, unit tests
uv run nox -s hub                            # against a hub built from this repository
uv run nox -s generate                       # after changing plsremind_discord/sql
```

The package layout:

| Path | What it holds |
|---|---|
| `plsremind_discord/hub.py` | the bot's only way to the hub, on top of the Python SDK |
| `plsremind_discord/reminders.py` | deliveries become direct messages |
| `plsremind_discord/sync.py` | messages follow changes made elsewhere |
| `plsremind_discord/views/` | the messages with buttons, built with hikari-risa |
| `plsremind_discord/commands/` | the commands, built with hikari-lightbulb |
| `plsremind_discord/modals.py`, `submits.py` | the modals and what happens when one is sent |
| `plsremind_discord/timeparse.py` | times as people type them |
| `plsremind_discord/sql/`, `db/`, `store.py` | the SQLite file; `db/` is generated by sqlc |
| `plsremind_discord/translations/` | every text, in English and German |
